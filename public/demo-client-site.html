Medicine / Product Price Live Stock Prescription Simulate Live Change

How Real-Time Data Works for Your Website:

Your website simply exposes window.EchoAIData before the script tag, OR adds data-api-endpoint="/api/stock". The AI reads live numbers instantly: 

<script>
  window.EchoAIData = {
    liveInventory: {
      "augmentin 625 duo tablet": { stock: 42, price: "₹185.50", rx: true }
    }
  };
</script>
<script src="./widget.js" data-agent-id="YOUR_AGENT_ID" defer></script>
